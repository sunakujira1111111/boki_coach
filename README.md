# 簿記2級コーチ

日商簿記2級の学習を、今日のメニューの決定から採点・誤答分析・復習・計画修正まで伴走するWebアプリ。
設計は [DESIGN.md](DESIGN.md) を参照。

## 使い方

PCで試す：`index.html` をブラウザで開く。

スマホで使う：このフォルダの中身を HTTPS の静的ホスティング（GitHub Pages など）に置き、
スマホのブラウザで開いて「ホーム画面に追加」する。初回の読み込み後は通信なしで動く。

学習データは端末のブラウザ内にだけ保存される。「その他 → 設定・バックアップ」から週1回はファイルに書き出すこと。

## 構成

| ファイル | 役割 |
|---|---|
| js/core.js | 日付、種から再現できる乱数 |
| js/grade.js | 仕訳の採点（順不同）、貸借一致、誤答原因の機械判定 |
| js/content.js | 配点表、論点マスタ、内蔵の解説 |
| js/templates.js | 問題の型とソルバー、出題前の検査 |
| js/mastery.js | 7つの証拠による理解判定、難易度、復習間隔 |
| js/planner.js | 学習計画、今日のメニュー、遅延判定、振り返りの集計、模試判定 |
| js/store.js | 保存、書き出し・読み込み |
| js/ui.js | 画面 |
| sw.js | オフライン用。ファイルを更新したら VERSION を上げる |

## テスト

ブラウザで開く。

- `tests/index.html`：採点・ソルバー（手計算と照合）・理解判定・計画。型ごとに300問ずつ生成して貸借一致などを検査
- `tests/smoke.html`：画面を自動操作して、初期設定から振り返りまで通す（本番とは別の保存先を使う）

## 型を追加するとき

`js/templates.js` に型を足し、`tests/tests.js` に手計算の正解を1つ以上足す。
対応する論点に解説がなければ `js/content.js` の `LESSONS` に足す。
正解は必ず `build` の中の計算で求める。文章に書いた数値と計算に使う数値を別々に持たない。

## 実装済みの範囲

設計書14章の段階0〜3と、段階7のうち教材模試の記録・判定。
内蔵問題があるのは16論点（商業の仕訳14、工業の仕訳2）。それ以外の論点は教材で学習して結果を記録する。
未実装：工業簿記の計算問題（段階4）、AI接続（段階6）、内蔵模試、第2問・第3問の総合問題（段階8）。
